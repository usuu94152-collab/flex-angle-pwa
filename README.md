# 유연성 기록 PWA

휴대폰 센서로 전후 굽힘, 좌우 굽힘, 몸통 회전 유연성을 측정하고 변화 추이를 혼자 기록·확인하는 개인용 React + TypeScript + Vite 앱입니다.

## 주요 기능

- 전후 → 좌우 → 회전 순서로 진행하는 일직선 측정
- 화면을 보지 않고도 측정할 수 있는 핸즈프리 흐름: 준비/측정 2단계 카운트다운과 소리·진동 신호
- 결과 화면에서 직전 기록과의 변화량 표시, 기록 화면에서 추이 그래프 제공
- 모든 기록은 브라우저 로컬 저장소에만 저장(서버 전송 없음)

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

같은 네트워크의 휴대폰에서 접속할 때는 다음 명령을 사용합니다.

```powershell
npm.cmd run dev:host
```

휴대폰 센서는 보통 HTTPS에서만 동작합니다. 실제 스마트폰 테스트는 HTTPS 배포 주소 또는 HTTPS 터널을 통해 확인하세요.

## 빌드

```powershell
npm.cmd run build
npm.cmd run preview
```

## 기록과 개인정보

측정 기록은 서버로 보내지지 않고 현재 브라우저의 로컬 저장소에만 저장됩니다. 기기나 브라우저 데이터를 지우면 기록도 함께 사라집니다.
